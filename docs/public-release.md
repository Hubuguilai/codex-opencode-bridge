# Experimental open-source scope — 0.2.0-rc.1

The owner authorized public experimental distribution on 2026-09-30 under the
repository's MIT license. This is a macOS-first trial, not a stable release or a
guarantee of feature parity with native GPT. GitHub visibility and the prerelease
page are the authoritative publication state; this file records intended scope.

Start with [the README](../README.md) or [中文教程](README.zh-CN.md). Big Pickle is
the default onboarding model. Muse Spark 1.3 Contributor Free is optional and
requires actual account/region access; payment is not a guaranteed fix for 403.

## Evidence

- 227 tests and macOS/Linux Node 22/24 CI passed for the onboarding implementation.
- Fresh temporary-home preparation without Node and repeat preparation passed.
- Real Codex through the isolated Router passed Big Pickle text/file tasks;
  managed installation repeat and uninstall passed.
- Earlier receipts cover Muse uploaded/tool-result images and bounded lifecycle
  and recovery scenarios. See [verification](verification.md) and
  [onboarding evidence](onboarding-verification.md) for exact revisions and limits.
- A pattern scan of 750 reachable historical Git blobs before publication found
  no matching key, private-key or maintainer-path patterns. This is not a complete
  secret or security audit.

## Still unverified or unsupported

- A separate clean Mac/user following the prompt through first Router setup,
  app restart and actual desktop model selection.
- A complete signed-in OpenCode registration/dashboard walkthrough; the guide's
  labels and paths were checked against official documentation and source.
- Automatic migration of arbitrary existing manual installations; full long-context,
  concurrent load and arbitrary crash-point certification.
- Windows/Linux desktop setup and native audio/video/PDF input.

The bridge uses the user's own access through the official OpenCode runtime.
No shared account, key, unlimited quota, or regional-access workaround is supplied.
Review upstream model data-use terms. Use the managed uninstall command rather
than deleting the checkout; see [security and lifecycle](security.md).
