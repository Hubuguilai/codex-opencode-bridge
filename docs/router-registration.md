# Router registration component

The bridge now has registration/removal commands for an explicitly selected,
already installed Codex Router. Automatic Router dependency installation and
version pinning are still pending. Do not describe this as the complete installer.

```sh
node bin/bridge.mjs register-router /absolute/plan-directory --router-root /absolute/router-directory
node bin/bridge.mjs unregister-router /absolute/plan-directory --router-root /absolute/router-directory
```

The plan is generated by the existing `prepare-router` command. Its source hashes
must still match current Router state. The selected Router must resolve to the
same state directory; the component refuses mismatches before mutation. An
existing provider with the proposed identity is not adopted or overwritten.

Registration uses the Router's cross-process model-overlay transaction, protected
credential store, user-model layer and shared publication path. The local bridge
token is copied to a private provider credential file, never emitted as command
output. Pre-mutation snapshots are saved privately under the plan's `backups`
directory. Treat these backups as sensitive local state; do not upload them.
Failed publication restores captured state through the Router's rollback path.
The Router may restart, but this command never restarts the Codex application.

Repeat registration checks owned objects and republishes without duplicating
models. Removal checks that the provider, model entries and credential have not
been edited, removes only the recorded models and provider, and republishes the
remaining catalog. Later unrelated models survive removal. If additional models
now depend on this provider, removal stops rather than breaking those models.
Keep the plan directory and registration record until uninstall is complete.

The current component has been checked against the installed Router modules in
isolated state: initial registration, repeat registration, injected publication
failure with rollback, dependent-model protection, and preservation of later
unrelated additions. The publication callback was stubbed in those tests. Actual
shared catalog publication, service restart and Desktop picker checks remain
pending for this new installer component.

Run the reproducible adapter check with an explicit Router checkout:

```sh
node scripts/router-registration-check.mjs /absolute/router-directory
```

It uses temporary Router state and does not publish to the installed clients.

## 中文说明

这组命令把模型注册到明确指定的已有 Router，并使用它原有的配置发布和恢复机制。
当前尚未自动安装 Router，也尚未完成新安装器的真实桌面菜单验收。

安装前保存私有备份；重复执行不会添加副本；移除只处理记录中的模型和供应商。
用户后来添加的其他模型会保留。如果用户修改过本项目的配置，或给同一供应商
增加了新模型，会停止自动移除并说明原因。备份可能包含本地认证信息，不要上传。

目前隔离测试已验证数据操作与失败恢复，但没有用这些测试替代真实菜单和重启验证。
